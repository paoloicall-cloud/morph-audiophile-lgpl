# Morph Audiophile — LGPL native libraries

Build scripts and source code of the LGPL libraries distributed with the Morph Audiophile Android app:
FFmpeg, mpv (libmpv) and their dependencies, and the FFmpeg decoder extension of AndroidX Media3.

- `native-lgpl/` — the scripts used to build the libraries (FFmpeg without `--enable-gpl`, mpv with `-Dgpl=false`).
- **Releases** — the complete corresponding source code of each distributed build, as required by the GNU LGPL.

This repository contains no code of the Morph Audiophile app itself.

---

Script di compilazione e codice sorgente delle librerie LGPL distribuite con l'app Android Morph Audiophile. Nelle *Releases* c'è il sorgente completo di ogni build distribuita, come richiede la GNU LGPL. Il codice dell'app non è incluso.
